# Loot

Personal finance app for South Africans. "Know your loot." — see how much money you actually have left this month.

This is the clean rebuild (React 19 + TypeScript + Vite + TanStack Router/Query + Tailwind v4 + Supabase), replacing the original Lovable prototype. See the Loot project docs (`LOOT-CONTEXT.md`, `LOOT-DESIGN-SYSTEM.md`, `LOOT-SCHEMA.md`, `LOOT-FEATURES.md`, `LOOT-BUILD-LOG.md`) for full product/architecture context.

## Setup

1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in your Supabase project's URL and publishable key:
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxx
   ```
3. In your Supabase project's SQL Editor, run Migration 001 (Profiles) from `LOOT-SCHEMA.md` — later phases will need the rest of the migrations.
4. Enable Email auth and Google OAuth under Authentication → Providers in the Supabase dashboard. Set the redirect URL to your dev/prod URL.
5. `npm run dev` — opens at `http://localhost:5173`. The terminal also prints a `Network:` URL for testing on your iPhone over the same WiFi.

## Scripts

- `npm run dev` — local dev server
- `npm run build` — type-check + production build (also regenerates the TanStack Router route tree first)
- `npm run preview` — preview the production build locally
- `npm run lint` — oxlint

## Notes

- `src/routeTree.gen.ts` is generated by TanStack Router (from `src/routes/**`) and is gitignored — it's created automatically the first time you run `npm run dev` or `npm run build`. Don't hand-edit it.
- Business logic and page components carry forward unchanged between phases per `LOOT-CONTEXT.md`'s session rules — check `LOOT-BUILD-LOG.md` before rebuilding anything.
